# 🖱️ Hand Gesture Virtual Mouse

A real-time computer vision project built in Python that uses your webcam to control the mouse cursor and perform clicks using hand gestures. 

Powered by **OpenCV**, **MediaPipe Tasks**, and **PyAutoGUI**.

---

## ✨ Features

- **Smooth Cursor Movement:** Uses exponential smoothing algorithms to remove jitter and ensure fluid mouse movements.
- **Pinch-to-Click:** Pinch your thumb and index finger together to trigger a left mouse click.
- **Visual Feedback:** Real-time webcam overlay with hand landmark indicators and click notifications.
- **Mirror Mode:** Automatic horizontal flipping for intuitive, mirror-like control.

---

## 🛠️ Tech Stack & Requirements

- **Language:** Python 3.x
- **Libraries:**
  - `opencv-python` (Webcam feed & display)
  - `mediapipe` (Hand landmark detection)
  - `pyautogui` (OS-level mouse control)
  - `numpy` (Mathematical transformations & distance calculations)
