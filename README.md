# 🖱️ AI Hand Gesture Virtual Mouse & Controller

A real-time computer vision project that turns your webcam into a touchless virtual mouse and media controller using Python.

## 🚀 Features
* **Virtual Mouse Cursor:** Track your index finger to seamlessly move your mouse cursor across the screen with built-in smoothing.
* **Pinch-to-Click:** Bring your thumb and index finger together to execute mouse clicks.
* **Volume & Media Control:** Adjust system volume or trigger shortcuts using hand gestures.
* **High Performance:** Built using modern MediaPipe Tasks API and OpenCV for low latency and high accuracy.

## 🛠️ Tech Stack
* **Python** (3.13+)
* **OpenCV** (Computer Vision & video capture)
* **MediaPipe Tasks** (Hand landmark tracking model)
* **PyAutoGUI** (OS-level mouse & keyboard simulation)
* **PyCaw** (Windows audio control)
